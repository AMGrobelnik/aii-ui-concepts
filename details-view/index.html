Details view — seven ways to group the stream

The Details page shows one flat, chronological list of events: a tinted type circle, a fifty-character AI summary, a chevron that expands the raw tool input and output. A substep like Evaluation 1 is about 165 of those rows; a whole run is 13,557 events and the feed caps at the latest 500. The question these seven mockups exist to settle is whether there should be one level of grouping between the substep and the row, and if so, what it should be.

Every page shows the same run, the same substep and the same numbers, so only the grouping differs. Two summarizers already exist and are free to reuse: the per-message label (50 characters, a few seconds behind the event) and the interim narrative (two paragraphs every two minutes, currently shown only on Overview). Where a variant needs something new, the build cost column says so. Leave a verdict and a note on each page; they are collected back here.
